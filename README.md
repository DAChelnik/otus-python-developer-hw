Создание телефонного справочника
====
Написать телефонный справочник, который будет сохранять контакты в файл и иметь следующий функционал:
- открыть файл
- сохранить файл
- показать все контакты
- создать контакт
- найти контакт
- изменить контакт
- удалить контакт
- выход

Пояснения и рекомендации к домашнему заданию
---
- в качестве «хранилища» контактов использовать формат json
- контакт минимально должен содержать имя, телефон и комментарий
- реализацию сохранения выполнить способом: загружать файл, создавать буферную копию для работы и в дальнейшем сохранять (или нет) внесенные изменения
- добавить функционал проверки изменений перед выходом (предлагать сохранить изменения)
- сделать поиск по контактам отдельно по полям (имя, телефон, комментарий), так и общий (поисковое слово ищет сразу во всех полях контакта)
- добавить всевозможные проверки, чтобы программа не крашилась в случае введенных неверных данных
